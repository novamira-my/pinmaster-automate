1. Who operates this application

PinMaster Automate (the "App") is a private content-scheduling tool operated by Novamira ("we", "us", "our"), reachable at clicknquest@gmail.com.

The App is not a public service and is not offered to other customers. It is used exclusively by its operator to publish content to Pinterest business accounts that the operator personally owns and controls. There are no other users, no customer accounts, and no third-party data.

2. Scope of this policy

This policy describes what data the App processes, why, how it is protected, and how it is deleted.

It does not cover Pinterest itself. Once a pin is published, Pinterest's own privacy policy governs that content: policy.pinterest.com/privacy-policy

4. What the App does not do

  • No passwords. The App never asks for, stores, or transmits a Pinterest password. Authentication is Pinterest OAuth 2.0 only.
  • No data about other Pinterest users. The App does not read, collect, store, or infer data about anyone other than the connected account owner. No follower lists, no other users' profiles, no scraping of public Pinterest content.
  • No unofficial access. The App uses only the official Pinterest API v5. It does not use browser automation, undocumented endpoints, or any technique intended to evade platform controls or rate limits.
  • No sale or sharing. Data is never sold, rented, licensed, or disclosed to third parties for advertising, profiling, or any other purpose.
  • No model training. Neither Pinterest data nor uploaded media is used to train machine-learning models.
  • No tracking. The App runs no advertising networks, no analytics products, and no tracking pixels. It sets no third-party cookies.
  • No engagement automation. The App does not follow, unfollow, comment, like, repin, or message on the operator's behalf. It publishes pins the operator has authored and nothing else.
  • No content generation. The App does not write, rewrite, spin, or otherwise alter titles or descriptions. Text is transmitted to Pinterest exactly as the operator wrote it.

5. Legal basis for processing

Where the GDPR applies, processing rests on:

  • Performance of a contract / legitimate interests — operating a tool at the request of, and solely for, its own operator.
  • Consent — authorization to access a Pinterest account is granted through Pinterest's own OAuth consent screen and can be withdrawn at any time (see section 9).

The only data subject is the operator, who is also the controller.

6. How data is stored and protected

  • Token encryption. OAuth access and refresh tokens are encrypted at rest using AES-256-GCM envelope encryption. The master key is held in a managed key-management service. Keys are never stored in source code or in plain environment variables.
  • Private media storage. Uploaded images are stored in a private object-storage bucket (Cloudflare R2). There is no public bucket and no CDN. Objects are never publicly readable. Browser access is granted only through short-lived presigned URLs issued to the operator's authenticated session.
  • Images are never exposed at a public URL. Pins are created using the Pinterest API's image_base64 source type, meaning image data travels directly from our private storage into a single API request to Pinterest. It is never placed at a fetchable public address.
  • Transport security. All traffic between the browser, the App, the object store, and the Pinterest API is encrypted with TLS.
  • Access control. The application interface is restricted to the operator at the network layer. There is no public sign-up and no shared access.
  • Least privilege. The App requests only the OAuth scopes it actively uses (see section 7).
